# Web Dev Projects

A collection of small front-end web development projects and exercises, each built as a standalone mini-project in its own folder. This repo serves as a practice space / portfolio of fundamental JavaScript, HTML, and CSS concepts.

## Projects

| Project | Description |
|---|---|
| [Calculator](./Calculator) | A basic calculator app for arithmetic operations. |
| [Dice roller program](./Dice%20roller%20program) | Simulates rolling one or more dice. |
| [Digital-clock](./Digital-clock) | A live digital clock display. |
| [Stopwatch](./Stopwatch) | A start/stop/reset stopwatch. |
| [Temperature-converter](./Temperature-converter) | Converts temperatures between units (e.g. Celsius/Fahrenheit). |
| [api-test-poke](./api-test-poke) | Experiments with fetching data from the PokéAPI. |
| [counter-program](./counter-program) | A simple increment/decrement counter. |
| [numb guessing game](./numb%20guessing%20game) | A number-guessing game. |
| [random num genrator](./random%20num%20genrator) | Generates random numbers. |
| [random password genrator](./random%20password%20genrator) | Generates random passwords. |
| [weather-app](./weather-app) | Fetches and displays current weather data from a weather API. |
| [web dev tests](./web%20dev%20tests) | Miscellaneous small experiments and test snippets. |
| [youtube homepage recreation](./youtube%20homepage%20recreation) | A front-end clone of the YouTube homepage layout. |

## Tech Stack

Each project is a standalone front-end exercise, typically built with:
- HTML
- CSS
- JavaScript

Some projects (like `api-test-poke` and `weather-app`) also fetch data from external APIs.

## Usage

Each folder is self-contained. To try a project:

1. Clone the repository:
   ```bash
   git clone https://github.com/dvyuh/web-dev-projects.git
   cd web-dev-projects
   ```
2. Open the project folder you're interested in and open its `index.html` file in a browser (or serve it with a local dev server, e.g. the VS Code "Live Server" extension).
